# ADR-0002: Navigation labels

- Status: Accepted (decided by the product owner on 2026-09-27)
- Date: 2026-09-26
- Deciders: Chandan Bharadwaj (product owner)

## Context
The brief names the journeys Bazaar, Canvas and Karigar. The boards use Shop, Create and Remix. First-time visitors must understand the nav without a glossary.

## Decision
nav labels are **Shop · Create · Remix**. Bazaar, Canvas and Karigar remain internal codenames and appear in brand copy where they add warmth (for example "Your karigar's note").

## Consequences
Code, routes and analytics use shop/create/remix. Copywriting guidelines list where the codenames may appear.
