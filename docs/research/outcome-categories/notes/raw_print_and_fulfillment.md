## KQ1. Service landscape as of 2026: status, developer APIs (auth, quote, order, status/webhooks, shipping), fees, MOQs, shipping reach

### Takeaway
The consumer-oriented "upload and print" market consolidated hard in 2024–2025 (Shapeways Chapter 7, i.materialise closed 31 Oct 2025, Sculpteo sold twice), while the API-ready survivors are Slant 3D (US FDM print farm, new v2 API Sept 2026), Craftcloud (multi-vendor aggregator with a public v5 API and worldwide shipping), Treatstock (marketplace API that includes at least one Indian bureau), JLC3DP (cheapest, China-based, partner-only Ordering API), Shapeways (relaunched under Manuevo, OAuth2 API with a 5% fee) and Sculpteo (token API). No Indian bureau exposes a public developer API; Xometry's developer API is supplier-facing, and Protolabs Network has no discoverable public API.

- Official PHP client: `createPrintablePack`, `changePrintablePack` (colours/materials), `getPrintablePackPrices` (pricesInfo: materialGroup, color, price, printer, providerId, rating, reviewsCount), `getPrintablePackOffers`, `placeOrder` (orderId, total, url), `payOrder` (account balance), `downloadReceipt`, `getMessages`/`sendMessage`; location by ISO country or client IP (default US); response includes `widgetUrl`/`widgetHtml` for an iframe configurator at `https://www.treatstock.com/api/v2/printable-pack-widget/?apiPrintablePackToken=...`; no webhook documented; credentials via support@treatstock.com — [Treatstock/apiv2](https://github.com/Treatstock/apiv2)
- REST endpoints: `POST /api/v2/printable-packs/?private-key=` (files[], files-urls[], location[country|ip], description); `GET /printable-packs/<id>` (calculated_min_cost, scaleUnit, largestPartSize, part size/weight); `PUT /printable-packs/<id>` (scaleUnit in|cm|mm, qty per part); `GET /printable-pack-costs/?printablePackId&location&printerMaterialGroup&printerColor` → {materialGroup, printer, color, price, providerId, url}; `POST /place-order/create` (printablePackId, providerId, email, shippingAddress, modelTextureInfo{color, materialGroup}) → {orderId, total, url}; `GET /material-group-colors/`; rate limits 7 concurrent GET / 15 POST / 30 PUT; `{"reason":"not_calculated_yet"}` means retry — [GitHub mirror: Treatstock_API_info.md](https://github.com/MattSharp05/shapeMint/blob/b9545ded8eed078f8c60a18fcc6d7f037ce39fa8/docs/API_information/Treatstock_API_info.md)

#### JLC3DP (JLCPCB, CN) — cheapest, partner-only Ordering API
- "Prices start from $0.30" with no minimum order; SLA, MJF, SLM, FDM, SLS and BJ; instant quote in seconds — [JLC3DP](https://jlc3dp.com/); [Instant quote](https://jlc3dp.com/3d-printing-quote)
- Two API options: a Pricing API (price comparison) and an Ordering API (upload STL/STP/STEP/OBJ/3MF, automatic pricing, ordering, status tracking); applications are reviewed and the Ordering API is for partners "with substantial experience in importing 3D printing parts from China and the capability to achieve a specified monthly order volume"; partners may not use the JLC3DP trademark, "JLC" in URLs, or the logo — [JLC3DP API application](https://jlc3dp.com/help/article/JLC3DP-API); [JLCPCB API platform](https://api.jlcpcb.com/)
- Technical surface (transcribed from the seven official JLC3DP OpenAPI PDFs): host `https://open.jlcpcb.com` (api.jlcpcb.com is only the portal), HMAC-SHA256 "JOP" signing, all POST under `/overseas/openapi/tdp/api/`: `upload` (multipart; stl/stp/step/obj/3mf/rar/zip; ≤80 MB; filename ≤50 chars), `file/result` (sizeX/Y/Z; `threeDimensionsMaterials[]` with materialTechnicsName e.g. "SLA(Resin)", colour list, `materialDeliveryVOList` {price e.g. 0.42, startPrice e.g. 0.14, deliveryDate in hours e.g. 48, deliveryType 1 expedited/2 normal}, `enableFlag`/`unableReason`, and a customs cascade `clearanceParamTreeDTOS`), `calculate` (→ `expressDetailResults[]` {expressName e.g. "dhl", shippingMoney, typeOfTrade}, `tdpCostsVOList[]` {unitPrice, price, weight g, limitWeight}), `order/create` (→ batchNum), `order/list`, `order/detail`, `order/process`; "Only one item currently supported" per cart DTO; per-product max `receiveShopMax` e.g. 100,000 and daily material cap `receiveOrderMaxG` e.g. 1,000,000 g — [GitHub mirror: hendley api-reference.md](https://github.com/holla2040/hendley/blob/23382d1485f6c02ebd407458a7c801e18b1b5652/docs/api-reference.md); the whole official partner API is "20 endpoints — 4 component/, 9 pcb/, 7 tdp/" — [KiCad-Lib notes](https://github.com/mszkowalik/KiCad-Lib/blob/c0c780d50a7476ec1f9da7edcd1da9287f6e0a34/docs/jlcpcb-web-api.md)
- Refunds: defective/damaged parts → full refund or replacement if reported within 7 days with photos/videos; refunds processed within 14 days of approval — [JLC3DP refund policy](https://jlc3dp.com/help/article/Refund-Policy-for-JLC3DP)
- Shipping to India: from China, standard 10–15 business days, express 3–7; import duties are the customer's responsibility unless DDP is arranged; JLC pre-collects taxes for some destinations; "total delivered cost including shipping and duties often exceeds local alternatives for simple parts" — [ThinkRobotics review 2025](https://thinkrobotics.com/blogs/learn/jlc3dp-3d-printing-service-review-india-complete-analysis-2025); [JLC US tariff FAQ](https://jlc3dp.com/help/article/us-tariff-policy-faq); [JLCPCB customs](https://jlcpcb.com/help/article/customs,-duties-and-taxes)
- Consumer UX evidence: the order page shows "a warning of printing risk, such as walls being too thin in a certain spot" that the user may ignore — [NadeshikoSlimeVR README](https://github.com/Aeurias/NadeshikoSlimeVR); ordering is "as straightforward as shopping on Amazon" — [Hackaday.io](https://hackaday.io/page/395320-trying-out-jlcs-3d-printing-service)

### Inferences
- For a startup shipping to the US and India, the practical API stack is: Slant 3D v2 for US-domestic FDM (cheap, API-first, PLA/PETG, 220 mm cube), Craftcloud v5 for everything else (resin, nylon, full colour, metal, non-US destinations, one integration to many vendors), Treatstock for marketplace routing (including Indian providers such as Objectify), JLC3DP Ordering API once monthly volume justifies the partner application (lowest unit prices but customs and 10–15 day transit into India), and Shapeways as a secondary SLS/MJF source (5% fee, OAuth2).
- Indian domestic fulfilment will initially need manual or negotiated integrations (email/portal, CSV) with bureaus like iamRapid/Imaginarium, 3Ding, Zbotic or Robu, since none publish developer APIs; iamRapid's instant-quote engine and Imaginarium's feasibility/preview tooling make them the most "API-shaped" candidates for a private integration.
- Xometry and Protolabs Network should be treated as B2B web-quote fallbacks, not programmatic partners: Xometry's public developer API addresses suppliers (Workcenter jobs), and no Protolabs Network API documentation exists.
- The 2024–2025 shake-out (Shapeways, i.materialise, Sculpteo, Forward AM) argues for a partner-abstraction layer with at least two interchangeable providers per material family rather than a single-vendor dependency.

## KQ2. Instant-quote logic: price computation, exposed parameters, size limits, file formats, printability checks, lead times, shipping

### Takeaway
Instant quotes are driven by geometry (volume, bounding box, weight), machine time/technology, quantity and production speed, with per-order minimums and shipping added at cart time; services expose technology, material, colour/finish, units/scale and quantity, and increasingly hide slicer settings (Slant fixes 0.2 mm layers and 20% infill; Craftcloud exposes only "infill variants" as quote types). Printability is enforced by a mix of automatic repair/hollowing (Sculpteo), parser feedback (Craftcloud `isParsing`, Treatstock `not_calculated_yet`), warnings the user can override (JLC3DP thin walls) and human review notes (Slant `notes` from the production team).

### Cited Findings
- Sculpteo: "The printing price of your design is calculated automatically the moment it is uploaded", based on "total volume, object size, and bounding box", and adjusts in real time with quantity, material, technology, finishing option and production delay; automatic hollowing removes interior material and adds powder-escape holes to cut material and machine time; repair algorithms analyse and repair files on upload and check printability — [How are prices calculated](https://learn.sculpteo.com/en/how-are-prices-calculated-1); [Reduce costs](https://learn.sculpteo.com/en/how-to-reduce-3d-printing-costs); [Repair tools](https://www.sculpteo.com/blog/2017/04/12/online-repairing-tools-diagnose-and-fix-your-3d-file/)
- Generic pricing formulas used by print shops: "Price = (Material + Machine time + Labor + Overhead) ÷ (1 − desired margin)" or "Total = (Material + Machine Time) × (1 + Margin)"; material cost = volume × density × price/kg; add 5–15% material for failures/waste; machine time from the slicer × hourly rate; electricity, depreciation, post-processing and waste as further components — [Siraya Tech](https://siraya.tech/blogs/news/how-to-price-3d-prints); [Omni Calculator](https://www.omnicalculator.com/other/3d-printing); [3DSPRO](https://3dspro.com/resources/blog/3d-printing-cost-calculators); [BuildYour3D](https://www.buildyour3d.com/en/blog/understand-3d-printing-costs)
- Treatstock's API returns per-model size and weight estimates and a `calculated_min_cost`, then per-provider prices by material group and colour; scale unit (in/cm/mm) and quantity are set on the pack — [Treatstock API docs](https://www.treatstock.com/help/article/83-api-documentation); [GitHub mirror](https://github.com/MattSharp05/shapeMint/blob/b9545ded8eed078f8c60a18fcc6d7f037ce39fa8/docs/API_information/Treatstock_API_info.md)
- Craftcloud's price request takes currency, destination country, per-model quantity and scale, and material configuration IDs; returns vendor quotes with `productionTimeFast`/`productionTimeSlow` and separate shipping options with `deliveryTime`; a cart adds `minimumProductionPrice.productionFee`; quote "types" include economy/expedited and infill variants — [GitHub mirror](https://github.com/MattSharp05/shapeMint/blob/b9545ded8eed078f8c60a18fcc6d7f037ce39fa8/frontend/supabase/functions/vendor-craftcloud-get-quote/index.ts); [craftcloud_api_merged.md](https://github.com/MattSharp05/shapeMint/blob/b9545ded8eed078f8c60a18fcc6d7f037ce39fa8/docs/API_information/craftcloud_api_merged.md)

### Inferences
- A robust in-house quote for the raw category can be computed from mesh volume × material density × ₹/$ per gram, plus a print-time proxy (volume and Z-height), a fixed setup/handling fee, and the partner's shipping quote; the same inputs (volume, bounding box, weight) are exactly what every partner API returns, so partner quotes can be used to calibrate an internal formula (e.g., Slant's estimate "including material weight").
- Minimum order/production fees (Craftcloud `minimumProductionPrice`, JLC `startPrice`, iamRapid ₹99) mean tiny consumer models are priced by the floor, not the geometry; the consumer UI should show a floor price up-front.
- Because each service's hard limits differ (Slant 220 mm cube/STL/250 MB; JLC 80 MB; Craftcloud SLS 700 mm), validation must be partner-aware and run before the quote is shown.

- Primary pages for Craftcloud "Understanding prices" and Sculpteo's price/delivery page were blocked; the exact weighting of volume vs bounding box vs machine time is not published anywhere I could reach.
- No per-technology minimum wall thickness table for FDM/resin was obtained from a reachable source (only SLS PA12 0.8 mm via Craftcloud's catalog and Xometry's 1 mm feature rule).

## KQ3. What a consumer "just print it" SKU should expose vs hide; preview; unprintable uploads; failed prints, refunds and reprints

### Takeaway
Consumer-facing services converge on exposing material family, colour/finish, size (with unit and scale), quantity and delivery speed, while hiding orientation, supports, layer height and infill; they preview the model in a 3D viewer with dimensions, block or warn on parsing/printability problems before checkout, and handle failures with photo-evidence reprint-or-refund windows (7 days at JLC3DP, 14 days at Craftcloud) and a handling fee when a chosen partner cannot print the file.

### Cited Findings
- Exposed parameters at Craftcloud (per a project's ordering guide): material (PLA+), finish (Standard), infill (20%) and quantity; at PCBWay: material, process (FDM 20% infill), design units (mm), quantity and a product category — [SO-ARM100 3DPRINT.md](https://github.com/TheRobotStudio/SO-ARM100/blob/5f6d2b876a53a4872e405b991dd925556c9e38a4/3DPRINT.md)
- Craftcloud's API models units (mm/cm/in) and scale explicitly and lets a model be "evolved" with a different unit; quotes come with economy/expedited variants and per-vendor production times — [craftcloud_api_merged.md](https://github.com/MattSharp05/shapeMint/blob/b9545ded8eed078f8c60a18fcc6d7f037ce39fa8/docs/API_information/craftcloud_api_merged.md)
- Treatstock exposes material group, colour, provider (with rating and review count), scale unit and quantity, and ships an embeddable iframe widget that renders the whole configurator — [Treatstock/apiv2](https://github.com/Treatstock/apiv2)
- JLC3DP exposes technology/material, colour, delivery speed (expedited/normal), quantity and a customs category, and shows a "printing risk" warning (e.g., thin walls) the user can accept — [hendley tdp reference](https://github.com/holla2040/hendley/blob/23382d1485f6c02ebd407458a7c801e18b1b5652/docs/api-reference.md); [NadeshikoSlimeVR](https://github.com/Aeurias/NadeshikoSlimeVR)
- Slant 3D exposes only filament/colour (PLA/PETG), quantity and optional supports; slicing, orientation, QC and post-processing are internal ("File Review → Slice → Print → … → QC Review → Approval → Post Process") — [Slant3D_API_info_NEW.md](https://github.com/MattSharp05/shapeMint/blob/b9545ded8eed078f8c60a18fcc6d7f037ce39fa8/docs/API_information/Slant3D_API_info_NEW.md)

- Preview: Imaginarium shows a rotatable 3D preview with orientation control and instant feasibility feedback; Slant returns `STLMetrics` (dimensions and a preview image) per file; Treatstock returns part size and weight; Craftcloud returns geometry (area, volume, x/y/z dimensions) once parsed — [Imaginarium](https://imaginarium.io/fast-track-on-demand-manufacturing-with-imaginariums-smart-quoting-and-manufacturing-platform/); [Slant3D_API_info_NEW.md](https://github.com/MattSharp05/shapeMint/blob/b9545ded8eed078f8c60a18fcc6d7f037ce39fa8/docs/API_information/Slant3D_API_info_NEW.md); [Treatstock_API_info.md](https://github.com/MattSharp05/shapeMint/blob/b9545ded8eed078f8c60a18fcc6d7f037ce39fa8/docs/API_information/Treatstock_API_info.md); [craftcloud_api_merged.md](https://github.com/MattSharp05/shapeMint/blob/b9545ded8eed078f8c60a18fcc6d7f037ce39fa8/docs/API_information/craftcloud_api_merged.md)
- Unprintable uploads: Sculpteo auto-repairs on upload; Craftcloud charges up to 7% handling if a model "turns out not to be printable by the partner you picked"; Slant orders are "only cancellable up until a part has printed" and files carry production-team `notes` — [Sculpteo repair](https://www.sculpteo.com/blog/2017/04/12/online-repairing-tools-diagnose-and-fix-your-3d-file/); [Craftcloud policy](https://support.craftcloud3d.com/en/articles/20-what-is-the-craftcloud-refund-reprint-policy); [Slant3D_API_info.md](https://github.com/MattSharp05/shapeMint/blob/b9545ded8eed078f8c60a18fcc6d7f037ce39fa8/docs/API_information/Slant3D_API_info.md)
- Failed prints/refunds: Craftcloud — manufacturer restarts failed prints and notifies on significant delay; claims within 14 days with photos; refunds 3–5 business days; refused packages incur reshipping plus the 7% fee — [Delayed orders](https://support.craftcloud3d.com/en/articles/30-my-order-is-delayed-what-could-be-the-reason); [Refund policy](https://support.craftcloud3d.com/en/articles/20-what-is-the-craftcloud-refund-reprint-policy). - Etsy compliance for outsourced 3D prints: listings must disclose the production partner and reflect the seller's role as designer — [Printie on Etsy standards (Nov 2025)](https://printie.com/blog/2025-11-16-etsy-creativity-standards-3d-printing)

### Inferences (recommended design for the raw "just print it" category)
- Expose: (1) material family as 3–4 plain-language tiers mapped to partner configs — "Standard plastic (PLA/PETG, FDM)", "Detailed resin (SLA)", "Strong nylon (SLS/MJF)", optional "Metal/full-colour" via Craftcloud; (2) colour from the partner's live catalog (Slant `/filaments`, Treatstock `material-group-colors`, Craftcloud materialConfigs); (3) size via a single longest-dimension slider with live bounding box and a unit toggle (mm/in), clamped to the partner limit (e.g., 220 mm for Slant); (4) quantity; (5) delivery speed (economy/expedited) where the partner supports it. Hide: layer height, infill, orientation, supports (auto-decide `support_enabled`), hollowing (apply automatically à la Sculpteo when volume is large), and vendor choice (pick cheapest-on-time server-side, Craftcloud style).
- Pricing formula: `consumer_price = max(partner_quote × (1 + margin), floor_price) + shipping + duties_estimate`, where partner_quote comes from the live API (Slant estimate, Craftcloud quotes, JLC calculate) and an internal fallback estimate uses volume × density × material rate + Z-height-based time proxy + fixed handling; show the floor explicitly for small parts.
- Validation pipeline before quoting: file type/size (STL ≤250 MB Slant, ≤80 MB JLC), unit sanity (flag models <10 mm or >220 mm), watertight/manifold repair (as Sculpteo does automatically), bounding-box vs partner limit, minimum wall/feature check (≥1 mm FDM/Xometry rule, 0.8 mm SLS per Craftcloud), and a partner parse round-trip (Craftcloud `isParsing`, Treatstock `not_calculated_yet`, Slant `STLMetrics`/`notes`); surface warnings JLC-style but block only on hard failures.
- Preview: render the repaired mesh in a 3D viewer with a dimension overlay and a scale reference object, since every partner already returns dimensions/weight and Imaginarium and Slant show previews.
- Failure/refund policy: adopt reprint-first with photo evidence within 14 days (Craftcloud) but no shorter than 7 days (JLC3DP); allow free cancellation until the partner reports printing (Slant rule); absorb the partner's unprintable-file handling fee (≤7%) only when the model passed your validation; pass the fee to the user when they override a warning.

### Gaps
- Could not access Craftcloud's own configurator UI or "Understanding prices" article to confirm exactly which slicer options it shows consumers; the infill exposure comes from a third-party ordering guide and API "types".
- No source quantified consumer reprint/failure rates at any service.

## KQ5. Practicalities for an Indian startup: cross-border shipping and customs (India↔US), domestic couriers, hybrid own-printers + partner model

### Takeaway
Since 29 Aug 2025 there is no US de minimis exemption, so India-to-US parcels attract full duties and India Post suspended US-bound merchandise parcels; producing US orders locally via an API partner (Slant 3D, Craftcloud US vendors) avoids this entirely. Into India, courier imports pay BCD + IGST on CIF with no low-value exemption, so Indian orders are best fulfilled domestically (Delhivery/Shiprocket-class couriers at roughly ₹25–90 per 500 g). Hybrid own-printer + print-farm fulfilment is an established pattern among small sellers (PrintPal, Printie, 3D Vikings, Slant 3D Shopify app), with Etsy requiring production-partner disclosure.

### Cited Findings
- The US ended de minimis for all countries on 29 Aug 2025 (Executive Order 14324 of 30 Jul 2025; China/HK already from 2 May 2025); the $800 threshold had allowed duty-free entry; Congress separately repealed Section 321 for commercial shipments effective 1 Jul 2027 — [NPR](https://www.npr.org/2025/08/28/nx-s1-5519361/de-minimis-rule-tariffs-consumers-imports-trump); [HLC](https://www.hlc.com/en/publications/de-minimis-customs-exception-for-small-packages-entered-into-the-united-states-to-end-in-august-2025); [Thomasnet](https://www.thomasnet.com/insights/de-minimis-shipments/); [eBay export guidance](https://export.ebay.com/en/resources/important-updates/us-tariffs)
- India Post suspended US-bound parcels on 25 Aug 2025 (only documents and gifts under $100); US tariffs on Indian goods stood at 50% at that time, hitting small-parcel exporters — [Xportel](https://www.xportel.com/blog/us-de-minimis-export-impact-india-2025); [Usthadian](https://www.usthadian.com/impact-of-us-de-minimis-rule-on-india-us-trade/)
- Importing into India: IGST of 5–28% applies on CIF + BCD; courier imports pay BCD, IGST and cess; the former ₹5,000 gift exemption was abolished; one 2026 guide says Union Budget 2026 set a flat 10% BCD on personal imports under CTH 9804; commercial/e-commerce shipments face stricter compliance — [Busy.in](https://busy.in/gst-rates/import-goods/); [DHL India](https://www.dhl.com/discover/en-in/logistics-advice/import-export-advice/import-duty-in-india); [iSend](https://isend.com.au/custom-duty-india-rules-you-must-know-before-shipping-to-india/); [Indian Customs courier manual](https://www.eximguru.com/exim/indian-customs/customs-manual/import-and-export-through-courier.aspx)
- JLC3DP's shipping into India takes 10–15 business days standard or 3–7 express, with duties normally paid by the recipient unless DDP; landed cost often exceeds local alternatives for simple parts — [ThinkRobotics](https://thinkrobotics.com/blogs/learn/jlc3dp-3d-printing-service-review-india-complete-analysis-2025); PCBWay parts likewise attract import taxes outside China — [SO-ARM100](https://github.com/TheRobotStudio/SO-ARM100/blob/5f6d2b876a53a4872e405b991dd925556c9e38a4/3DPRINT.md)
- Domestic couriers: Delhivery charges ₹50–90 per 500 g; small local parcels from ~₹40; Shiprocket is an aggregator over 17+ couriers with surface rates around ₹25–45 per 500 g; charges use chargeable weight (higher of actual vs volumetric), zone and surface/air mode — [Shiprocket on Delhivery](https://www.shiprocket.in/blog/delhivery-courier-charges/); [The Shizz comparison](https://theshizz.in/blog/courier-comparison-shiprocket-delhivery-bluedart); [Shiprocket rates guide](https://www.shiprocket.in/blog/compare-courier-delivery-shipping-charges-india/)
- Indian bureaus ship pan-India with short lead times: Robu free shipping and 1-day lead time; iamRapid 3-day delivery; 3Ding 24–48 h — [Robu](https://robu.in/robu-launched-3d-printing-service-instant-quotation-multicolor-printing/); [iamRapid](https://iamrapid.com/); [3Ding](https://3ding.in/print/)
- Hybrid/outsourced fulfilment for small sellers: PrintPal pitches "a print farm or hybrid fulfillment" for overflow; Printie prints, QCs and ships from a US facility; 3D Vikings prints and ships under the seller's brand with "no printers, no inventory, and no monthly fees"; Slant 3D's Shopify app and Printago connect stores to farms; 3DQue's Direct2Print automates Etsy orders on the seller's own printers; Etsy requires disclosing the production partner — [PrintPal](https://blog.printpal.io/how-to-start-selling-3d-printed-models-on-etsy-a-beginners-guide/); [Printie](https://printie.com/blog/2025-11-16-etsy-creativity-standards-3d-printing); [3D Vikings](https://3dvikings.com/); [Slant Shopify app](https://apps.shopify.com/slant); [Printago](https://apps.shopify.com/printago); [3DQue](https://www.3dque.com/direct2print-etsy-landing-page)
- Slant 3D markets "remote production" so products "designed in one country [are] produced and fulfilled in another country without the cost of shipping" — [Slant 3D blog](https://www.slant3d.com/slant3d-blog/reduce-import-and-fulfillment-costs-with-remote-production-via-3d-printing); Manuevo likewise positions Shapeways' Eindhoven plant to serve EU/US customers "without the burden of import duties" — [3D Printing Industry](https://3dprintingindustry.com/news/shapeways-relaunched-in-europe-as-manuevo-following-asset-acquisition-232193/)

### Inferences
- Route by destination: US orders → US-based partner via API (Slant 3D v2 for FDM; Craftcloud with countryCode=US for other materials); India orders → own printers plus Indian bureaus, shipped by an aggregator (Shiprocket-class) to keep 500 g parcels in the ₹25–90 range; avoid India→US parcel exports for consumer orders post-de-minimis.
- Because JLC3DP's landed cost into India includes duties and 1–3 weeks transit, it fits only high-value or exotic-material orders, not sub-₹500 consumer prints.
- A hybrid model is normal at small scale; the app should record the fulfilling partner per order (also needed for Etsy-style disclosure) and keep an internal fallback estimate when a partner API is down.

### Gaps

- Actual duty-inclusive landed-cost examples for a small parcel India→US or US→India, and DHL/FedEx/Aramex India export rates for 500 g parcels, were not obtained.
- The Budget 2026 "flat 10% BCD under CTH 9804" claim rests on a single secondary source and should be verified against CBIC notifications.
