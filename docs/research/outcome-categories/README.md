# Outcome categories research (27 Sep 2026)

Question: a customer's idea becomes a model, but what does it become *physically*? Which everyday objects can be standardised as **carriers** that fuse the user's idea with a usable thing (keychain, magnet, nameplate, ornament, lithophane, figurine base, keycap, frame …), with what specs, and how should the one raw **"just print my model"** category work?

| File | What it is |
|---|---|
| `report.md` | Synthesised research report: findings, recommended tiered carrier taxonomy (Deliverable A), raw-category design (Deliverable B), evidence-quality note (Deliverable C) |
| `implementation-plan.md` | Phased, resumable implementation plan for this repo: template families as data, content-slot features (`relief_image`, `hero_mesh`), carrier templates, `raw_print` path, hardware + setup pricing, API/UI, PR steps and tests |
| `notes/consumer_demand.md` | What personalised 3D-printed products people buy, price bands, occasions, market size, India gifting players |
| `notes/competitor_patterns.md` | MakerWorld MakerLab, customizer marketplaces, AI-to-3D services with print ordering (Meshy Creative Lab), print-on-demand catalogue model |
| `notes/engineering_standards.md` | Per-category hardware specs, minimum walls, materials and safety, mesh-fusion toolchain and licences, shape-tolerance classes |
| `notes/raw_print_and_fulfillment.md` | Upload-and-print services, instant-quote logic, partner APIs (Slant 3D, Craftcloud, Treatstock, JLC3DP, Shapeways), Indian bureaus, customs and shipping |
| `notes/pricing_economics.md` | Cost floors, retail bands, print-on-demand margin norms, market size and seasonality, business-model recommendation |

Method and caveat: five parallel researchers plus a report writer (deep-research skill). Full-page fetches were blocked by the sandbox network proxy and the shared search budget was exhausted, so findings rest on search-result snippets and public GitHub mirrors of official docs. Every figure carries currency, date and source URL; treat numbers as medium-confidence and re-verify against primary pages before publishing or pricing from them. The notes still carry their original "note to coordinator" headers about the write-path redirect; they are harmless provenance.
